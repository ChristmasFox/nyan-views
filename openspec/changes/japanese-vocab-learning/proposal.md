## Why

项目要从通用演示首页转向**日语词汇学习**产品：以 JLPT 级别（先 N5，逐步扩展到 N2）为主线，用成熟间隔重复（SRS）与卡片式训练帮助用户掌握常用词。当前首页的大屏/演示内容需要让位给学习入口，原功能暂存以便日后恢复。

## What Changes

- **首页**：改为日语学习产品首页（入口、今日路线/打卡入口占位、级别与模式说明等）；原 `HomePage` 中的大屏列表、计数器、`ReduxTest` 等演示内容**迁移到独立组件文件暂存**，主路由**不再引用**。
- **应用路由**：`app/page.tsx` 不再为学习首页拉取 `displayGroups` 等演示数据（或仅保留与演示页无关的数据层，以实施为准）。
- **后续实现**（本变更规格与设计覆盖，分任务落地）：
  - 叠卡片式单词训练；可选 **打字模式**（仅输入）或 **语音模式**（先语音识别 → 重试 → 打字过关）。
  - 发音（TTS 或音频）；宽松语音识别判分（基于识别文本相似度，阈值可配），第二阶段再加强。
  - 成熟 SRS 调度；词条带近似 JLPT 标签（N5–N2），支持单选级别或混选；循序渐进扩展词表范围。
  - 成功提示音等轻量趣味反馈；每日复习路线与本地打卡/streak（**无登录**，数据仅存本机）。
  - 响应式布局，兼顾 PC 与移动端。

**BREAKING**：对依赖「首页即大屏管理」的用法而言，默认首页行为改变；原 UI 仅保留在仓库中未挂载的暂存组件内。

## Capabilities

### New Capabilities

- `japanese-learn-home`：学习产品首页、全局导航与学习入口占位（与演示首页解耦）。
- `vocab-training`：JLPT 标签词表、SRS、卡片 UI、打字/语音双模式作答流程、发音与音效、宽松语音判分与第二阶段改进边界。
- `local-daily-route`：每日复习路线、本地 streak/打卡、无账号持久化（localStorage/IndexedDB 等，由设计定稿）。

### Modified Capabilities

- （无）当前 `openspec/specs/` 下尚无既有能力规格。

## Impact

- **前端**：`app/page.tsx`、`components/home/*`；新增学习相关页面与组件；暂存组件如 `LegacyHomeHome` 或 `StashedDemoHome`。
- **数据**：演示用 `displayGroups` 查询从首页移除；SRS/词表/进度为客户端或后续静态/本地 JSON，本阶段不强制后端。
- **依赖**：可能增加 SRS 相关库、Web Speech API 使用；音效资源文件。
- **浏览器**：语音与 TTS 需 HTTPS 与现代浏览器；移动端能力差异需在规格中说明。
